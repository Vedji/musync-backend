# Contributing

## Commit message style

В проекте используется формат [Conventional Commits](https://www.conventionalcommits.org/).

Формат сообщения:

```text
<type>: <description>
```

Основные типы:

- `feat` — добавление новой функциональности
- `fix` — исправление ошибки
- `docs` — изменения документации
- `refactor` — изменение структуры кода без изменения поведения
- `test` — добавление или изменение тестов
- `chore` — служебные изменения, настройка окружения, зависимостей и инфраструктуры

Сообщение коммита должно быть коротким и описывать одно логическое изменение.
