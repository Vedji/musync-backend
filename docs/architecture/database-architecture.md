# Архитектура базы данных

База данных используется для хранения структурированных данных приложения: информации о пользователях, устройствах, музыкальной библиотеке и пользовательских плейлистах.

Музыкальные файлы непосредственно в `PostgreSQL` не хранятся. В базе данных сохраняются только метаданные и информация, необходимая для получения файла из объектного хранилища `MinIO`.

## Основные группы сущностей

Структуру базы данных можно разделить на несколько логических групп:

- пользователи и устройства;
- музыкальная библиотека;
- плейлисты.

### Пользователи и устройства

Таблица `users` хранит данные пользователей приложения.

Основные поля:

- идентификатор пользователя;
- имя пользователя;
- хэш пароля;
- роль;
- дата создания и изменения записи.

Таблица `devices` содержит информацию об устройствах, с которых пользователь подключается к системе.

### Музыкальная библиотека

Основу музыкальной библиотеки составляют следующие сущности:

- `artists` — хранит информацию об исполнителях;
- `albums` — хранит информацию о музыкальных альбомах и связанных с ними исполнителях;
- `tracks` — хранит информацию об отдельных музыкальных композициях и их принадлежности к альбому и исполнителю;
- `media_files` — хранит техническую информацию о физическом аудиофайле и ключ объекта в `MinIO`.

Разделение `tracks` и `media_files` позволяет отделить логическую музыкальную композицию от её физического представления.

### Плейлисты

Для хранения пользовательских плейлистов используются следующие таблицы:

- `playlists` — хранит информацию о плейлисте;
- `playlist_items` — связывает плейлист с треками и хранит порядок их расположения.

Такое разделение позволяет одному треку присутствовать в нескольких плейлистах.

## Связь с объектным хранилищем

Музыкальные файлы хранятся в `MinIO`, а `PostgreSQL` содержит метаданные и ключ, по которому сервер может получить соответствующий объект из хранилища.

Таким образом, `PostgreSQL` используется для хранения структуры и метаданных приложения, а `MinIO` — для хранения аудиофайлов.

## Основные связи

Основные отношения между сущностями:

- один пользователь — несколько устройств;
- один пользователь — несколько плейлистов;
- один исполнитель — несколько альбомов;
- один альбом — несколько треков;
- один трек — один или несколько медиафайлов;
- один плейлист — несколько элементов;
- один трек может входить в несколько плейлистов.
